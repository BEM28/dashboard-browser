# Dashboard Browser

Halaman beranda pribadi untuk browser, dibuat dengan [Next.js](https://nextjs.org) dan Tailwind CSS.

- Background dot yang bergerak dan menyorot mengikuti mouse
- Sapaan dengan nama yang bisa diganti
- Jam dan tanggal
- Pencarian Google (tekan `/` untuk fokus; alamat web langsung dibuka)
- Bookmark yang bisa ditambah, diubah, dihapus, dan diurutkan lewat tombol pengaturan
- Todo list sederhana

Nama, bookmark, dan todo disimpan di localStorage browser.

## Menjalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
